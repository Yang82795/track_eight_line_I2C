# 重走古丝路循迹避障小车程序

本程序已按仓库中的比赛地图与规则重新整理，目标是优先稳定完成 **4 个赛段 + 4 次无碰撞避障 + 终点停车**，而不是只在直线赛道上跑得快。

## 已针对赛道做的改动

- **20 mm 黑线、8 路传感器**：不再只匹配少数几个二进制位型。`line_pid.cpp` 对所有检测到黑线的探头计算加权质心，因此单点、相邻多点、急弯、S 弯都能持续给出误差。
- **正确的 PID**：使用 `当前误差 - 上次误差` 的微分项、积分限幅、弯道自动降速；丢线时原地向最后一次看到黑线的一侧搜索，而非带着速度冲出赛道。
- **非阻塞避障状态机**：超声波正前方连续两次确认障碍后停车，舵机分别扫描左右，自动选择净空更大的一侧。随后执行“斜出 → 平行越过 → 斜回 → PID 回线”，不再使用原来固定的 `LeftCar()/RightCar()` 两段延时动作。
- **适配随机左右摆放**：四个障碍物不再假定在固定方向；左右扫描结果相近时会交替选择绕行方向，避免总是向同一侧场地边缘偏移。
- **赛段标识抗误触发**：近物体必须连续确认才启动避障；每次回线后有短暂锁定时间，避免对同一障碍物/标识重复绕行。
- **终点停车**：确认已进入普通循迹线、起跑一段时间后，连续识别到 7 路以上黑色的横线才停车。这样会忽略起点横线，并在终点横线处立即刹停，以争取停止分。
- **控制周期与安全**：删除 I2C 读取中的 `delay(10)` 和高频串口打印；I2C 读取失败立即停车，避免用旧传感器数据继续运行。

## 比赛地图参数（已体现在策略中）

| 项目 | 规则中的数据 | 程序处理 |
| --- | --- | --- |
| 场地 | 6200 mm × 2000 mm | 避障失败回线时优先丢线搜索，避免盲目长时间直行至场外 |
| 循迹线 | 黑色、宽约 20 mm | 8 路黑线加权质心与弯道降速 |
| 障碍物 | 共 4 个，每段 1 个，在线的一侧随机摆放 | 超声波前探 + 左右扫描，自适应选择绕行侧 |
| 最大障碍物 | 最大平面尺寸 150 mm × 100 mm；最高 170 mm；第 4 个有 1 kg 配重 | 默认绕行通过时间留出了“障碍物 + 车长 + 安全余量” |
| 起终点 | 20 mm × 500 mm 黑横线 | 7 路以上同时压黑、45 ms 确认；仅在起跑 8 s 后启用终点停车 |

## 接线与传感器约定

| 功能 | 引脚 |
| --- | --- |
| 左电机 PWM / IN1 / IN2 | D3 / D4 / D5 |
| 右电机 PWM / IN1 / IN2 | D11 / D9 / D10 |
| 超声波 Trig / Echo | D8 / D7 |
| 超声波舵机 | D6 |
| 起跑按键（可选） | D2，内部上拉 |
| 8 路循迹模块 | I2C `0x12`，寄存器 `0x30` |

程序默认沿用原硬件协议：`x1` 是车体**最左**探头、`x8` 是最右探头；**黑线输出 0，白底输出 1**。若你的模块输出正好相反，请在 `readLineSensor()` 中对读取字节取反：

```cpp
const uint8_t data = ~Wire.read();
```

## 上场前必须标定的 5 项

不要直接把时间参数当作所有车都适用的值。电机减速比、轮胎、供电电压和舵机安装角度都会影响结果。每次只改一个参数，并在胶带上记录结果。

1. **确认传感器极性和顺序**
   临时将 `SERIAL_DEBUG` 改为 `1`，把黑胶带分别放到左、中、右。黑线在右边时，小车必须向右修正；否则检查探头顺序/极性。正式比赛改回 `0`。
2. **确认舵机左右方向**
   `SERVO_LEFT_ANGLE` 必须看向车体左侧，`SERVO_RIGHT_ANGLE` 必须看向右侧。默认 `145/45` 只是常见安装方向；反了就交换这两个值，否则会朝障碍物绕行。
3. **先调直线和弯道 PID**
   参数在 `line_pid.cpp` 顶部。蛇形弯振荡：先降低 `LINE_KP`（每次 1～2），再略升 `LINE_KD`；转弯迟缓/易丢线：小幅提高 `LINE_KP`。确认稳定后才提高 `LINE_SPEED_STRAIGHT`。
4. **调转向角与横向距离**
   在地上放最大尺寸的模拟障碍物。调 `AVOID_TURN_MS` 到每次原地转约 45°；然后以车体任何部件都不擦碰障碍物为准，调整 `AVOID_OUTWARD_MS`。空间不够时宁可加大此值，不要只提速。
5. **调绕过长度与回线**
   `AVOID_PASS_MS` 必须覆盖“最大障碍物沿路线尺寸 + 小车长度 + 余量”；车尾还未超过障碍物就回线会碰撞。确认安全后再逐步减小它以提速。回线过冲则减小 `AVOID_OUTWARD_MS` 或提高 `AVOID_INWARD_MIN_MS`。

## 关键可调参数位置

- `line_pid.cpp`：`LINE_SPEED_STRAIGHT`、`LINE_SPEED_TURN`、`LINE_KP/KI/KD`。
- `motor_car.cpp`：`MOTOR_LEFT_SCALE`、`MOTOR_RIGHT_SCALE`。车辆直行总偏一边时，用 0.96～1.04 的小幅比例修正，优先于增大积分。
- `track_eight_line_I2C.ino`：舵机角度、障碍检测距离、避障 PWM/时间、终点识别时间。

> 建议正式比赛使用较保守的避障距离和绕行时间。单个成功避障有 10 分，四个共 40 分；比起在障碍旁边追求极限速度，稳定避开并回到黑线通常得分更高。
