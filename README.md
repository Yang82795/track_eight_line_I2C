# 重走古丝路循迹避障小车程序（融合优化版 V5）

本版本由两套独立实现**综合比对、取长补短**融合而来：

- **根目录原版（V4，事件式非阻塞状态机）**
- **`智能巡线避障小车-ds/` 版（另一 agent 实现：100Hz 定周期 + 先刹后判终点判定 + 独立避障模块）**

两套代码项目完全相同、目标一致（优先稳定完成 **4 赛段 + 4 次无碰撞避障 + 终点停车**）。本版逐模块择优合并，并补齐了各自的短板。`智能巡线避障小车-ds/` 目录整体保留，作为对照与出处参考。

## 融合决策（谁的实现更优就用谁，并互补缺点）

| 模块 / 能力 | 根目录原版 | -ds 版 | 本版采用 |
| --- | --- | --- | --- |
| 主循环架构 | 事件式非阻塞状态机 | **100Hz 定周期 + 状态机 + 软里程/时间基准** | ✅ -ds |
| 巡线算法 | 8 路加权质心 + 整数 PID | **mm 物理量质心 + PD + 弯道减速 + 偏差包络** | ✅ -ds（融合原版的**积分限幅**） |
| 终点判定 | 7 路黑 + 45ms（发夹易误触发） | **多重闸门 + "先刹后判"厚度/里程鉴别** | ✅ -ds（明显更强） |
| 避障 | 非阻塞状态机（纯开环定时） | **pulseIn 自测距（无库依赖）+ 贴边偏置通过** | ✅ -ds（融合原版**两侧接近时交替绕行**） |
| 电子刹车 | 无（可能滑行越线丢分） | **`Car_brake` 反向制动** | ✅ -ds |
| I2C 读失败 | 立即停车（fail-safe） | 沿用上次值（防瞬时误判） | ✅ **两者融合**：沿用上次值 + **连续失败计数兜底停车** |
| 电机比例校正 | **`MOTOR_LEFT/RIGHT_SCALE`** | 无 | ✅ 原版 |
| 起步方式 | 无（按键被注释） | 按键起步 | ✅ -ds 按键 + **新增可选 `AUTO_START` 自动起步** |
| 超声波库依赖 | 依赖 `HCSR04` 库 | **无外部库依赖** | ✅ -ds（更少现场坑） |
| 文档 | 详尽《比赛调试与优化指南》 | 《现场调试步骤与待定夺清单》《调参说明》 | ✅ **三份全部保留** |

> 相对 -ds 版新增的融合改进：
> 1. **巡线 PID 增加积分限幅**（`I_LIMIT`），抑制调试暂停/首帧的微分尖峰（来自原版思想）；
> 2. **I2C 连续失败兜底停车**（`I2C_FAIL_STOP_CNT`）：单次失败沿用上次值防抖，连续 5 次判定线松脱后停车，避免带旧数据高速冲出赛道；
> 3. **左右电机比例校正**（`MOTOR_LEFT/RIGHT_SCALE`）：机械不对称优先在此微调，不靠大积分补偿；
> 4. **避障两侧净空接近时交替绕行**，避免总往同一侧场地边界偏移；
> 5. **可选自动起步**（`AUTO_START`），兼顾"对齐起始线后按键放行"与"一键自动放行"两种现场需求。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `track_eight_line_I2C.ino` | 主程序：100Hz 定周期 + 状态机（IDLE/RUN/SEARCH/DONE）+ 起步 + 终点"先刹后判" + I2C 兜底 + 串口调试 |
| `line_pid.cpp/.hpp` | 巡线核心：I2C 读 8 路 → 连续质心偏差(mm) → PD + 弯道减速 + 积分限幅 → 事件上报(丢线/宽黑/全黑) + 软里程 |
| `avoid_obstacle.cpp/.hpp` | 避障：`pulseIn` 版超声波（不依赖 HCSR04 库）+ 舵机 4 点扫描 + 交替绕行 + 偏出/贴边通过/收尾 |
| `motor_car.cpp/.hpp` | 运动层：`Set_speed / Set_speed_ex / Car_drive / Car_stop / Car_brake / Car_pivot` + 左右比例校正 |

## 上车前必须标定的项目（都在各文件顶部 `#define`）

| 项目 | 位置 | 怎么标 |
| --- | --- | --- |
| 传感器极性 | `line_pid.cpp` → `BLACK_IS_ZERO` | 串口看 `m=`：压黑线时对应位应为 **0**；若相反改成 `0` |
| 传感器间距 | `line_pid.cpp` → `SENSOR_PITCH_MM` | 卡尺量相邻两路红外中心距（常见 10~12mm） |
| 里程系数 | `line_pid.cpp` → `MM_PER_PWM_SEC` | 跑完一圈看串口最后一行 `d=`(cm)，与真实赛道长比对后按比例改 |
| 舵机左右 | `avoid_obstacle.cpp` → `SERVO_L*/SERVO_R*` | 打到 `SERVO_L1(80)` 看车头是否朝左；反了就两组宏对调 |
| 电机方向/起转 | `motor_car.cpp` → 引脚宏 / `IGNORE_SPEED` | 台架测 `Car_drive(100,100,1)` 两轮是否都前进 |
| 直行跑偏 | `motor_car.cpp` → `MOTOR_LEFT/RIGHT_SCALE` | 持续偏一侧时用 0.96~1.04 微调，每次 0.01~0.02 |

## 接线与传感器约定

| 功能 | 引脚 |
| --- | --- |
| 左电机 PWM / IN1 / IN2 | D3 / D4 / D5 |
| 右电机 PWM / IN1 / IN2 | D11 / D9 / D10 |
| 超声波 Trig / Echo | D8 / D7 |
| 超声波舵机 | D6 |
| 起跑按键 | D2，内部上拉 |
| 8 路循迹模块 | I2C `0x12`，寄存器 `0x30` |

约定：`x1` 是车体**最左**探头、`x8` 是最右探头；**黑线输出 0、白底输出 1**（可用 `BLACK_IS_ZERO` 反转）。

## 起步方式

- 默认 `AUTO_START = false`：上电后串口提示对齐起始线，**按 KEY(D2) 起步**。
- 若现场希望一键自动放行，把 `track_eight_line_I2C.ino` 顶部 `AUTO_START` 改为 `true`。

## 串口调试输出（`DEBUG_SERIAL 1`，每 300ms 一行）

```
st1 m=F8 n=0 k=3 e=-5 v=6 t=12 d=345 D=850 L=850 R=850 S=-1
```

- `st` 状态：0 待机 / 1 巡线 / 2 原地找线 / 3 结束
- `m` 8 路掩码（1 白底、0 压线）；`n` 黑点数；`k` 黑块形态（0 正常 / 1 宽黑 / 2 全黑 / 3 丢线）
- `e` 偏差 mm（正=线在车右侧）；`v` 偏差包络 mm；`t` 已跑秒数；`d` 里程 cm
- `D` 前方距离 mm；`L/R` 左右扫描 mm；`S` 避障判定侧别（+1 障碍在右向左绕 / -1 障碍在左向右绕）
- 事件行：`GO` / `CROSS-FALSE`（发夹误报继续跑）/ `FINISH-STOP`（终点确认）/ `LOST-STOP`（丢线超时停车）/ `I2C-FAIL-STOP`（传感器掉线兜底停车）
