## 0. 使用说明

1. **先填第 8 节的 D1/D2**（终点判定策略、速度档位），再开始动手——这两个决定会影响后面所有阶段的门限值。
2. 按 **A → G** 顺序做，**不要跳阶段**：A 是台架、B/C/D 是赛道单项、E 是避障、F 是联调。
3. 每个小项都按同一格式写：**【目的】【操作】【观察】【通过判据】【不通过改哪一行】【记录】**。
4. 参数定位写成 `文件名:行号`，例如 `line_pid.cpp:24` = `Speed_Line`。
5. 每次改动只改**一个**参数，改完立刻回测，并记到第 11 节。
6. ⚠ **安全**：调试时车会突然窜出去，台架阶段请垫空轮子或用手扶稳；超声波/舵机测试时手不要停在车头正前方 10cm 内（会读成很近）。
7. ⚠ **合规**：正式比赛日请把 `track_eight_line_I2C.ino:29 DEBUG_SERIAL` 改成 `0` 并拔掉 USB 线（避免被判"人工干预/远程控制"）。

### A2 传感器极性 / 间距 / 离地高度

【目的】确认 `0 = 压黑线`，并量出真实间距（影响偏差换算）
【操作】把车放到黑线上，串口看 `m=`；然后用手把车**横向慢慢平移**过线
【观察】`m=` 的哪些位变 0、变化顺序、`n=` 的数值
【通过判据】
- 压线时对应位 = **0**（`m=` 里 0 的个数 = `n=`），白底处 = 1
- 平移时 0 的位**逐位移动**，能看出哪一端是 x1（x1 = m 的最高位 = 最左那路）
- 正常压线时 `n` 应为 **1~4**（20mm 线 + 约 11mm 间距）
【不通过改哪一行】
- 极性相反（压线是 1） → `line_pid.cpp:22 BLACK_IS_ZERO` 由 `1` 改 `0`
- `n` 长期为 0 或 8 → 传感器离地太高/太低，调到 **8~12mm**，加遮光罩（避环境光）
【记录】极性 ____ ；相邻两路中心间距 ____ mm（回填 `line_pid.cpp:21 SENSOR_PITCH_MM`）；离地高度 ____ mm

## 3. 阶段 C：弯道与发夹（**最高风险项，必须自造复现**）

> 背景：我量过地图，赛道里有一处尖峰（图 x≈1290~1375，约在全程 18% 处），两条腿的黑带之间只剩约 **21mm 白缝**、中心线转弯半径只有 **30~60mm** —— 8 路排宽 70~80mm 的比例转向**跟不住**，必须靠"丢线→原地转找回"。这一节就是验证这条保命逻辑。

### C1 单个 90° 弯
【操作】用胶带贴一个直角弯（转角半径约 5cm 也行），车以巡线状态通过
【通过判据】不出现 `st2`（或出现后 0.5s 内回到 `st1`）；不脱线
【不通过改哪一行】`line_pid.cpp:25 Speed_Min` 85→90~95（弯里再慢一点）

### C2 自造发夹弯（对应地图那处尖峰）
【胶带摆法】（用 18~20mm 哑光黑胶带）
```
  ══════════════════════════════      ← ① 顶部横贴 80mm 一段, 把两腿连成黑块
        ║                  ║           ← ② 左腿 / 右腿, 各一条 20mm 胶带
        ║   白缝 ≈20mm     ║
        ║  (中心距≈40mm)   ║
        ║      ↑           ║
        ║   车沿右腿上行    ║  ← 把车放在右腿上(离顶部 ≥300mm), 朝上起步
        ║                  ║
        ║                  ║
        ↓ 出弯后沿左腿向下继续走(此时车头已转过约180°)
```
摆法步骤：
1. 找一段直道，先贴**右腿**：200mm 长直胶带（车从这里进）；
2. 平行贴**左腿**：与右腿中心距 **40mm**（白缝约 20mm），长 200mm；
3. 顶部用 **80mm** 胶带横向连通两条腿（模拟"两腿合并成黑块"）；
4. 把车放在右腿**远端**（离顶部 ≥300mm），朝顶部方向按 KEY 起步。**不要**直接把车放在顶部黑块里。

【观察】串口日志：应出现 `n=` 变大到 5~8 → `st1 → st2`（原地转）→ 回到 `st1`
【通过判据】
- 能自己找回线并继续前进（方向正确：朝上次偏差方向转，`line_last_dir`）；
- 不出现 `FINISH-STOP`（发夹**绝不能**被判成终点）；
- 最坏情况允许出现 `CROSS-FALSE`（那只是多花 0.3~0.6s）。
【不通过改哪一行】

| 现象 | 改哪里 | 方向 |
|---|---|---|
| 转错方向 / 找不到线 | `line_pid.cpp:35 ERR_DIR_MEM_MM` | 4.0→6.0（方向记忆更稳） |
| 原地转太慢、转不回来 | `track_eight_line_I2C.ino:34 SEARCH_PWM` | 62→70 |
| 频繁进 `st2`（还没丢线就找） | `.ino:32 SEARCH_LOST_MS` | 60→80~100 |
| 转很久还找不到 | `.ino:33 SEARCH_TIMEOUT_MS` | 1300→1600（上限 2000，再大易逆行） |
| 直接冲过顶部跑飞 | `line_pid.cpp:26 Speed_Crest` | 75→68；`line_pid.cpp:27 Speed_Lost` 同步 |

## 4. 阶段 D：终点判定三组对照试验（**做完才能上赛道**）

> 背景：终点线是 500mm×20mm 的黑色横线，而发夹弯顶部两腿合并也会变成黑块 —— 两者读数很接近。代码用"**先刹后判**"：命中候选立刻电子刹车，再用 68 PWM 慢爬 ≤450ms，看黑块是不是"薄横线"（250ms 内结束→终点；一直黑→发夹）。这一节就是把三种情况各测一遍，把门限值定死。

### D1 正穿横线
【操作】在直道上横贴一条 **500mm × 20mm** 黑胶带，垂直跨过循迹线（两侧各伸出约 240mm），车沿线直穿过去
【通过判据】串口出现 `FINISH-STOP`，且车**停在横线附近**（车尾没有越过横线）

### D2 斜穿横线（重点！地图上起始/终点线就是斜穿的）
【操作】同一条胶带，改贴成与循迹线约 **45°**，再改 **60°**，各跑一次
【通过判据】两次都出现 `FINISH-STOP`
> 几何原因：斜穿时 8 路**不可能同时全黑**，只会到 5~6 路；所以检测门限用的是"黑点数 ≥ `CROSS_WIDE_CNT`(5)"而不是"8 路全黑"。

### D3 发夹黑块（绝不能误停）
【操作】
1. 用 C2 的自造发夹；
2. **临时**把闸门关掉：`.ino:36 CROSS_MIN_MS` → `0`，`.ino:37 CROSS_MIN_MM` → `0`；
3. 车放在发夹前 400mm 起步；
4. **测完必须改回** `12000` / `4500`（否则赛道中段会被误触发）。
【通过判据】出现 `CROSS-FALSE` 且车**继续跑**；**绝对不允许**出现 `FINISH-STOP`
【不通过改哪一行】

| 现象 | 改哪里 | 方向 |
|---|---|---|
| D1/D2 完全无反应（跑过去不停） | `.ino:41 CROSS_WIDE_CNT` | 5→4 |
| 仍无反应 | `.ino:40 CROSS_ENV_MM` | 32→999（临时全关，先确认能停） |
| 仍无反应 | `.ino:37/36 CROSS_MIN_MM / CROSS_MIN_MS` | 按第 9 节实测赛道长取 50%，时间取实测单圈 60% |
| D3 误停（发夹被当终点） | `.ino:46 CREEP_CLEAR_MS` | 250→150 |
| D3 误停（车斜着爬出发夹侧边） | `.ino:40 CROSS_ENV_MM` | 32→20 |
| D1/D2 停了但车尾越过横线（丢停止分） | `.ino:43 BRAKE_MS` | 90→110；或降 `Speed_Line` |

## 5. 阶段 E：避障（4 种摆位 × 各 3 次）

## 6. 阶段 F：全程联调与计时（≥5 圈）

【目的】把"能跑完"变成"稳定跑完 + 有时间分"

### 附：三组关键概念的速查（便于答辩/写报告）

1. **为什么不用"枚举 8 路位型"？** 20mm 线 + 约 11mm 间距，正常压线只有 1~4 路；再叠加发夹黑块/斜穿横线，位型会有几十种，枚举必漏。改用**连续质心偏差**（单位 mm），PD 直接作用在物理量上，任何位型都有定义。
2. **为什么终点线不能用"8 路全黑"判？** 地图上起始线/终点线是**斜穿**赛道的：几何上斜穿时整排传感器**不可能同时全黑**（只会到 5~6 路）。所以门限取"黑点数 ≥5"。
3. **怎么区分"终点横线"和"发夹黑块"？** 靠**沿路径的厚度**：终点横线只有 20mm 厚，无论正穿斜穿，黑块沿路径只有 20~60mm；发夹顶部两腿合并的黑块沿路径 150mm 以上。代码用"先刹 → 68PWM 慢爬 ≤450ms/≈90mm"测这个厚度，250ms 内黑块消失才算终点。
